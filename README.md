
# Sort Visualizer

**Sort Visualizer** is an interactive desktop application that helps you **learn and understand sorting algorithms** through step-by-step visualizations. Built with **.NET 8**, **Avalonia UI**, and **CommunityToolkit.Mvvm**, it’s designed for both students and developers who want to see algorithms in action.

---

## Features

You can explore classic sorting algorithms like **Bubble Sort**, **Quick Sort**, **Insertion Sort**, and **Selection Sort**. The app allows you to play, pause, step forward or backward, jump to any point in the algorithm, and restart at any time. Playback speed is adjustable from 0.25x to 2x, giving you full control over the learning pace.

Data can be generated in different modes, including random, reversed, nearly sorted, or with many duplicates, and you can also manually input your own numbers with built-in validation. As the visualization runs, pseudocode is highlighted in real time, and detailed information about each algorithm - such as descriptions, pros and cons, complexity, 
and code snippets - is displayed alongside the animation.

## Getting Started

Make sure you have **.NET 8 SDK** installed. Then, simply run:

```bash
dotnet run
```

to launch the app.

---

## Why Use This App?

Sort Visualizer is perfect for visual learners who want to **see how sorting algorithms work in real time**. It’s also useful for developers looking to refresh their knowledge or experiment with different data arrangements.

---

## Tech Stack

The app leverages **.NET 8**, **Avalonia UI**, and **CommunityToolkit.Mvvm** to provide a smooth, cross-platform experience.
